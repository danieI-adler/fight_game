# Fight Game

Jogo de luta 2D para navegador com 20 personagens.

---

## 🎮 Controles

### Jogador 1 (P1)
- **Mover**: `A` / `D`
- **Pulo**: `Espaço` ou `W`
- **Agachar**: `S`
- **Bloqueio (Defesa)**: `E` ou `Shift Esquerdo`
- **Soco Fraco / Forte**: `F` / `R` (ou `J` / `U`)
- **Chute Fraco / Forte**: `G` / `T` (ou `K` / `I`)
- **Habilidade Especial**: `Q`
- **Super Golpe**: `Enter`

### Jogador 2 (P2)
- **Mover**: `←` / `→`
- **Pulo**: `↑`
- **Agachar**: `↓`
- **Bloqueio (Defesa)**: `Num 0` ou `Ctrl Direito`
- **Soco Fraco / Forte**: `Num 4` / `Num 7`
- **Chute Fraco / Forte**: `Num 5` / `Num 8`
- **Habilidade Especial**: `Num 9`
- **Super Golpe**: `Num Enter`
